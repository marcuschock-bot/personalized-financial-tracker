# Harbor Finance

Harbor Finance is a focused personal finance tracker MVP built with plain HTML, CSS, and JavaScript. It runs without a backend and stores data in the browser with `localStorage`.

## Run locally

Open `index.html` directly in a browser, or serve the repository with any static file server. The optional validation command is:

```bash
npm run check
```

The initial view includes clearly labelled demo data. Use **Reset demo data** to restore the original sample state at any time.
